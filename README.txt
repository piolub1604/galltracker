GALLTRACKER PWA

1. Rozpakuj archiwum.
2. Wgraj wszystkie pliki i katalog icons do głównego katalogu repozytorium GitHub.
3. GitHub: Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
4. Otwórz opublikowany adres w Safari na iPhone.
5. Udostępnij -> Dodaj do ekranu głównego.

Dane wpisów są zapisywane lokalnie w przeglądarce na danym urządzeniu.
Przed zmianą telefonu wybierz Ustawienia -> Eksportuj kopię JSON.
Na nowym telefonie wybierz Importuj kopię JSON.
